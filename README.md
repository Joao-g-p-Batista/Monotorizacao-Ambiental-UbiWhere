# Projeto-Monotoriza-o-ambiental-Ubiwhere
Monotorização Ambiental com Sensores Low-Cost e ESP32

Este repositório contém o desenvolvimento de um projeto industrial de monitorização ambiental, utilizando sensores low-cost e a plataforma ESP32 para a recolha e processamento de dados. 

Os dados são formatados e enviados via protocolo MQTT para integração na base de dados da empresa UbiWhere.

O projeto foi desenvolvido com base no framework Arduino para ESP32, garantindo eficiência e flexibilidade na implementação. O objetivo é fornecer uma solução robusta e escalável para a monitorização contínua de parâmetros ambientais, como temperatura, humidade, qualidade do ar, entre outros.

Destinado ao nosso cliente, este repositório inclui toda a documentação, código-fonte e informações técnicas necessárias para a replicação e adaptação do sistema.
